# MotionClass

MotionClass помогает проводить интерактивные уроки на общей онлайн-доске. Учитель запускает урок, ученик подключается к нему, а заметками на доске можно управлять жестами перед веб-камерой.

Проверить проект можно прямо в браузере, без установки: [motion.lytsites.online](https://motion.lytsites.online/).

## Как войти и проверить проект

В базе уже подготовлены два аккаунта и класс. Данные для входа:

| Роль | Почта | Пароль |
| --- | --- | --- |
| Учитель | `teacher@mail.ru` | `12345` |
| Ученик | `student@mail.ru` | `12345` |

Класс называется **11А**. Ученик уже добавлен в этот класс. Аккаунты и класс хранятся в `backend/data/motionclass.sqlite`.

Для проверки одновременно откройте проект в двух отдельных профилях браузера, например в обычном окне и в режиме инкогнито. В первом войдите как учитель, во втором как ученик.

1. Учитель открывает раздел «Урок» и нажимает «Начать внеплановый урок».
2. В панели доски учитель нажимает «Управление камерой» и разрешает доступ к веб-камере.
3. Ученик открывает раздел «Урок». Когда появится активное занятие, нажимает «Подключиться».
4. Ученик включает камеру и поднимает руку выше головы примерно на полсекунды. У ученика появится подтверждение, а у учителя на доске появится заметное уведомление с именем ученика и кнопкой «Сбросить».
5. Чтобы проверить работу с доской, учитель может добавить заметку, переместить её жестом и перейти на следующий лист. Ученик увидит изменения на общей доске.
6. Учитель завершает урок кнопкой «Завершить урок». Доска сохраняется, а урок появляется в истории.

Управление камерой можно включить отдельно у учителя и ученика. Для проверки уведомления о поднятой руке достаточно включить камеру у ученика; учителю камера не нужна.

## Жесты

Наведите ладонь на нужное место доски. Курсор показывает положение её центра. Камера работает в браузере, видео не отправляется другим участникам.

| Что сделать | Что произойдёт |
| --- | --- |
| Навести ладонь на заметку или кнопку | Курсор переместится к выбранной цели. Для выбора кнопки наведите курсор и сожмите кулак. |
| Сжать кулак над заметкой и двигать рукой | Заметка будет перемещаться вместе с рукой. Чтобы закончить перемещение, полностью раскройте ладонь. |
| Показать жест V и провести рукой влево или вправо | Доска переключится на предыдущий или следующий лист. |
| Показать две руки и свести или развести ладони | Изменится размер заметки, на которую была наведена рука. |
| Поднять руку выше головы и удерживать | Ученик поднимет руку, преподаватель получит уведомление. |
| Открыть окно добавления материалов, показать V и двигать рукой вверх или вниз | Список материалов прокрутится в соответствующую сторону. На самой доске вертикальный жест V для прокрутки не используется. |

Чтобы добавить заметку камерой, наведите курсор на кнопку «Заметка» и сожмите кулак. Если доска пустая, можно выбрать «Добавить заметку» в центре доски.

## Подсказки при ошибочном жесте

Подсказки включены постоянно. Если жест похож на нужный, но выполнен неточно, приложение объясняет, что поправить. Например, при неполном кулаке просит плотнее сомкнуть пальцы; при неверном направлении жеста V подсказывает вести ладонь по нужной оси; если рука потерялась из кадра, предлагает вернуть её в область камеры. Для поднятия руки приложение подскажет поднять кисть выше головы.

## Локальный запуск

Понадобятся Node.js 20 или новее, npm и Python 3.10 или новее. Для Windows откройте PowerShell в папке проекта и выполните:

```powershell
npm install
py -3 -m venv backend/.venv
.\backend\.venv\Scripts\python.exe -m pip install -r backend/requirements.txt
npm run dev
```

Если команда `py` недоступна, вместо неё используйте `python -m venv backend/.venv`.

Откройте `http://localhost:5173` и разрешите браузеру доступ к камере.

Для macOS или Linux создайте виртуальное окружение и установите зависимости так:

```bash
npm install
python3 -m venv backend/.venv
backend/.venv/bin/python -m pip install -r backend/requirements.txt
npm run dev
```

## Технологии

Интерфейс сделан на React, TypeScript и Vite. Жесты и позы распознаются MediaPipe прямо в браузере. API написан на FastAPI, данные хранятся в SQLite. Модели и файлы MediaPipe находятся в `frontend/public`, отдельно скачивать их не нужно.
